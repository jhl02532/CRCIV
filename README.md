## 홈페이지 개요

CRCIV의 공식 홈페이지입니다. 곤충 감각생리, 질병 매개체 제어, 비교 게노믹스, 그리고 바이오센서 기술을 연구하는 센터를 소개합니다.

### 📚 주요 페이지

- **index.html** - 홈페이지 메인 페이지
- **research.html** - 5대 연구 분야 상세 소개
- **publications.html** - 논문 및 출판물 목록
- **team.html** - 연구팀 소개
- **contact.html** - 연락처 및 문의

## 🔬 연구 분야

### 1. Insect Taste Receptors (곤충 미각 수용체)
- Apis mellifera, Apis cerana의 맛 감지 메커니즘
- 모기 등 질병 벡터의 미각 신경생물학

### 2. Disease Vector Control (질병 매개체 제어)
- 모기의 혈액 섭식 행동 연구
- 살충제 및 기피제 효과성 평가

### 3. Insect Olfaction (곤충 후각)
- 안테나 구조 및 냄새 수용체 분석
- 종 간 후각 시스템 비교

### 4. Comparative Genomics (비교 게노믹스)
- Apis cerana 게놈 시퀀싱
- 곤충 종 간 진화 특성 분석
- lincRNA 및 유전자 발현 연구

### 5. Biosensors & AI Applications (바이오센서 & AI)
- 곤충 수용체 기반 바이오전자 혀 개발
- 식품 품질 검사 시스템
- 화학 센싱 플랫폼
